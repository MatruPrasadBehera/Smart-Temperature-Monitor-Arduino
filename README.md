## 📖 Project Overview

This project was developed as part of my **Embedded Systems & Internet of Things (IoT) Internship** at **Maincrafts Technology**.

The Smart Temperature Monitor continuously measures environmental temperature using a **DS18B20 Digital Temperature Sensor** connected to an **Arduino Uno**.

Depending on the measured temperature, the system classifies it into three states:

- 🟢 SAFE
- 🟡 WARNING
- 🔴 DANGER

The LEDs indicate the current condition while a buzzer alerts the user whenever the danger threshold is reached.

The project was completely designed and tested using the **Wokwi Online Simulator**.

# ⚙ Working

1. Read temperature from DS18B20.
2. Compare with threshold values.
3. Display current status.
4. Turn ON corresponding LED.
5. Activate buzzer during danger.
6. Display data on Serial Monitor.
